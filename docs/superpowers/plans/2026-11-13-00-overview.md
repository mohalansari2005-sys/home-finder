# Home Finder — Implementation Plan Overview

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the private, Arabic-first Home Finder web app described in the spec, in 5 milestones. Each milestone produces working, testable software.

**Architecture:** A single Python package `homefinder` (in `backend/`) contains the FastAPI server, the LangGraph agent, the pure logic (scoring, dedupe, learner, visits) and the Mac worker. Server and worker install the same package with different extras. Postgres+PostGIS is the only datastore and also the job queue. The frontend (`web/`) is a static React+Vite PWA served by nginx.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 (sync, psycopg 3), GeoAlchemy2, Alembic, LangGraph + langchain-openai, OpenAI SDK, httpx, curl_cffi, Playwright, Pillow, imagehash, scikit-learn (worker only), pytest. React 19 + Vite + TypeScript, Tailwind CSS v4, react-router 7, @tanstack/react-query 5, @vis.gl/react-google-maps, vite-plugin-pwa, vitest, Playwright Test. Docker Compose, nginx, certbot, Tailscale, launchd.

**Spec:** `docs/superpowers/specs/2026-11-13-home-finder-design.md`

## Global Constraints (apply to every task in every plan)

- **Python 3.12** (`python3.12 -m venv backend/.venv`). `uv` is not installed; use pip.
- **Postgres 16 + PostGIS 3.4** (`postgis/postgis:16-3.4` image). Tests use `deploy/docker-compose.test.yml` on port **55432**.
- **Server RAM budget (2 GB VPS):** `db` mem_limit 512m, `api` mem_limit 640m, uvicorn `--workers 1`. **No Chromium, Playwright, curl_cffi browser, scikit-learn or Pillow in the server image.** These live in the `worker` extra only. (Exception: `curl_cffi` is allowed in the server for the M3 fallback search.)
- **The repo is PUBLIC.** Never commit `.env`, API keys, cookies, real seller phone numbers or names, or the family's place coordinates. Scrub every fixture with `scripts/scrub_fixture.py` before committing; `tests/test_fixtures_scrubbed.py` enforces this.
- **Never hardcode cookies or session tokens** for any site.
- **Scrape politely:** sleep `uniform(2, 3)` s between requests to the same site; with 1% probability sleep `uniform(5, 10)` s instead.
- **Every paid external API call** (OpenAI, Google) goes through `homefinder.usage.guard(...)`, which enforces the monthly caps `OPENAI_MONTHLY_CAP_USD` and `GOOGLE_MONTHLY_CAP_USD`.
- **Null over guess:** unknown values stay `None`/`NULL`. Never invent defaults for listing fields.
- **Sanity ranges** (value outside → `None` + log warning): price 100,000–100,000,000 SAR; built area 50–5,000 m²; land area 50–20,000 m²; building age 0–80 years; street width 4–100 m; bedrooms 1–20; bathrooms 1–20.
- **Time:** timezone `Asia/Riyadh`. The Saudi workweek is **Sunday–Thursday**. Store timestamps as `timestamptz` in UTC.
- **Frontend:** every UI string is in Arabic; `<html lang="ar" dir="rtl">`; use only logical Tailwind utilities (`ms-/me-/ps-/pe-/start-/end-/text-start/text-end`). Never use `ml-/mr-/pl-/pr-/left-/right-/text-left/text-right`. Breakpoints: phone `< 768px`, iPad `768–1199px`, desktop `≥ 1200px` (Tailwind `md: 768px`, `xl: 1200px`; set `--breakpoint-xl: 1200px`). Numbers use `Intl.NumberFormat('ar-SA-u-nu-latn')` (Western digits); currency suffix `ر.س`.
- **Arabic UI rules:** `docs/arabic-ui-rules.md` is binding for all `web/` work (formatting via `lib/format.ts` only, `<bdi>` number islands, `pluralAr`, verbal-noun buttons, hamzas, no typed symbols for controls). Where it differs from code shown in a plan, the rules file wins. For example, `formatPrice` uses `Intl.NumberFormat('en-US')`, not `'ar-SA-u-nu-latn'`.
- **No hover-only actions** in the UI. Every action must be reachable by tap.
- **Commits:** small, conventional (`feat:`, `fix:`, `test:`, `chore:`, `docs:`). **Do NOT add `Co-Authored-By` or "Generated with Claude Code" lines** (repo owner's rule).
- Run backend tests from `backend/` with `.venv/bin/pytest`. Run frontend tests from `web/` with `npm test` / `npx playwright test`.

## Review Focus (for all milestones)

1. **Malformed source data:** `price: 0`, `""`, a string price `"1,200,000"`, `area: null`, `location: null`, `imgs: null`. The listing must still ingest with those fields `None` and no crash. Pinned in Plan 1 Task 4 (`test_parse_malformed_values`).
2. **Listing with no coordinates and no district:** `geo_precision='none'`. It's left off the map but shown in the feed with "—" commute chips; enrichment doesn't call Google. Pinned in Plan 1 Task 7 (`test_enrich_without_location`).
3. **Mac sleeps mid-job:** a claimed job gets reclaimed after 15 min and finishes exactly once, with no duplicate pending jobs for the same `dedupe_key`. Pinned in Plan 1 Task 2 (`test_reclaim_stale_then_complete_once`).
4. **Re-scraping the same listing with a new price:** still one listing, one new `listing_price_history` row, and only one pending `enrich_listing` job. Pinned in Plan 1 Task 5 (`test_reingest_price_change`).
5. **Auth edge cases:** a wrong password returns 401; the 6th attempt within 60 s from the same IP returns 429; `/api/*` without a session returns 401 and the SPA redirects to `/login`; `/worker/*` without the token returns 401 (nginx also denies non-Tailscale IPs). Pinned in Plan 1 Task 8 (`test_login_rate_limit`, `test_worker_requires_token`).
